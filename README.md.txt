# Clinic Appointment Data Analysis & Visualization Dashboard

## 📌 Project Overview

This project is an end-to-end **Data Analytics and Data Visualization project** based on clinic appointment data.

The project includes data cleaning and preprocessing using Python, exploratory data analysis (EDA), data visualization using Python libraries, and an interactive dashboard developed using Power BI.

The main objective is to transform raw clinic appointment data into meaningful insights that can help understand patient demographics, appointments, billing, departments, follow-up requirements, and waiting periods.

---

## 🎯 Objectives

* Clean and preprocess the raw clinic appointment dataset.
* Perform Exploratory Data Analysis (EDA).
* Analyze patient demographics and appointment patterns.
* Analyze department-wise and doctor-wise appointments.
* Analyze billing amounts and waiting periods.
* Analyze follow-up requirements.
* Create meaningful visualizations using Python.
* Build an interactive Power BI dashboard.
* Extract important insights from the data.

* Patient demographics

* Average waiting period
* Department-wise appointment analysis
* Gender analysis

The dashboard allows users to explore the data interactively and identify important patterns.

---

## 🔑 Key Insights

The analysis generated the following key insights:

* **Neurology** recorded the highest number of appointments with **273 appointments**.
* The dataset contains **527 female** and **473 male** appointments.
* The average patient age is **53.75 years**.
* The average billing amount is approximately **275.8**.
* **514 appointments** require follow-up, while **486 appointments** do not require follow-up.
* The average booking-to-appointment waiting period is approximately **274.56 days**.
* The maximum recorded waiting period is **728 days**.
